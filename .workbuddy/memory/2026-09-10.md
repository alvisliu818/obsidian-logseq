## 修复：`{{embed ((uuid))}}` 嵌入块不渲染
- 根因1（主因）：`renderTree.attachStaticContent` 里先跑 `enhanceBlockRefs` 再跑 `enhanceEmbeds`。BLOCK_REF_RE 会命中 embed 语法里的内层 `((uuid))` 并替换成 chip，文本节点被拆开，EMBED_RE 再也匹配不到 → 只显示 `{{embed <chip>}}` 原文。改为先 `enhanceEmbeds` 后 `enhanceBlockRefs`。
- 根因2：`serializeBlockContent` 把子块按 depth+1（一个 tab）缩进输出，tab 缩进的列表无法打断段落 → 整棵子树被渲染成一坨连在一起的段落。改为子块 depth 0 + 空行分隔。
- 附带：嵌入/拖拽预览里过滤掉 `id::` / `collapsed::` 记账属性（`PREVIEW_SKIP_PROPS` + `serializeBlock` 新增可选 skipProps 参数）。
- 新增 `tests/serializer.test.ts`（3 例）。vitest 151 passed，已重新 build 并同步到插件目录。
- 已知边界：跨文件嵌入依赖 blockIndex，目标块所在文件还没落盘时会短暂显示 block not found（embedCache 不缓存 null，重渲染后恢复）。

## 修复：嵌入块点哪行都只编辑根块
- 原因：embed body 是「整棵子树 md 一次性 MarkdownRenderer」，DOM 里没有块级映射，点击只能拿到 EmbedSource 根块。
- 改法：改为**逐块渲染**——`renderEmbedRow` 递归生成 `.embed-row`（子块放 `.embed-children`），每行用 `embedRows` WeakMap 记住 `{src, path}`（path = 从嵌入根块出发的 child-index 路径，子块没 id 也能定位）。
- `treeOps.blockAtPath(root, path)` 新增（带单测）；`startEmbedEdit(box, src, path)`、`writeEmbedText(src, path, text)`、`applyBlockText(id, path, text)` 全部 path 化；同文件/跨文件（已开 BlockEditorView / 读盘改块写回）都按 path 定位目标块。
- `EmbedSource` 去掉 md 字段（不再整段渲染）；styles 加 `.embed-row` hover + `.embed-children` 缩进线。152 tests pass，已 build + 同步。

## 修复：点嵌入块后显示 `{{embed ((id))}}` 原始源码
- 原因：嵌入框内点击会冒泡到宿主块的 `wireContentEvents` → `focusBlockFromClick(宿主块)` → 宿主块进入编辑，露出 `{{embed ((uuid))}}` 源码。两个漏点：① `is-editing` 时早退没有 stopPropagation（在编辑器里点第二下必炸）；② 未解析/加载中或点面包屑时提前 return 也没 stopPropagation。
- 改法：`createEmbedBox` 里 `e.stopPropagation()` 提到最前（嵌入框吞掉自己所有点击）；`wireContentEvents` 增加兜底 `if (closest('.block-embed')) return;`（放在 anchor / block-ref 判断之后，保留框内链接可用）；加载中点击不再跳转，只有 `is-broken` 才 openBlockRef。

## 修复：列表项里开代码围栏（body 不缩进）导致后续内容被吞成 raw 块
- 复现：`- \`\`\`sql` + 顶格的 `create database test;` + ` \`\`\` ` + `- 删除库` → 解析成 `[list]"```sql"` + `[raw]"create database test;\n```\n- 删除库\n..."`，后面所有块被吞成一坨纯文本（渲染异常）。
- 原因：parser 只在「fence 行缩进 ≥ 块深+1」时按块内围栏处理；`- \`\`\`` 这种「列表项本身就是围栏起始行」没覆盖，后续行既不是围栏缩进也不是列表，全掉进 rawBuf。
- 改法：list 分支创建块后，若 `text` 命中 FENCE_OPEN_RE 且同一行没有闭合围栏（避免 `用 \`\`\`code\`\`\` 表示` 误判），用新增的 `consumeFenceBody()` 把围栏体吃到该块 text（body 行 stripIndent(1)，闭合行要求同字符且长度 ≥）。
- 新增 parser 回归测试 2 例（围栏起于列表项 / 行内反引号不触发）。154 tests pass，已 build + 同步。
- 注：旧文件不会丢内容（raw 块原样序列化），重载后会自动重新解析成正确块结构。
