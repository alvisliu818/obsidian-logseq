
## 光标不显示修复（caret overlay 从未真正画出来）
- 用户报告：空大纲项编辑无光标、有内容块行首无光标。
- 根因：`styles.css` 里 `.lgp-caret-overlay` **缺 `position: fixed`** —— caretOverlay.ts 用 JS 设 left/top（viewport 坐标），static 元素上无效，白条被留在 body 文档流末尾，永远不可见。
- 修复：CSS 补 `position: fixed; top:0; left:0`，宽度 1px→1.2px（对齐原生 .cm-cursor），JS 偏移改 `left - 0.6` 居中。
- 验证（e2e，端口 9330）：空行 + 英文行首 + **CJK 行首**（difference blend 对「空」字形）三场景截图确认光标可见、blink 正常；`_diag-caret-overlay-full.mjs` / `_diag-caret-zoom-cjk.mjs` 可复跑。
- ⚠️ 环境坑（下次 e2e 必看）：
  - 测试 Obsidian 秒退 `FATAL: GPU process isn't usable` → spawn 参数必须加 `--disable-gpu-sandbox --enable-unsafe-swiftshader`。
  - WorkBuddy 环境有 HTTP 代理劫持 127.0.0.1 → 跑 e2e 要 `NO_PROXY=127.0.0.1,localhost`。
  - Bash 工具两次调用之间 detached 进程会被清掉 → 启动+诊断必须合并在单次调用里跑。
  - 测试库 `E:/HOME/Local/logseq-e2e-vault` 的插件副本是独立拷贝，改完要单独 cp（主库部署流程不含它）。
- 已部署主库（cmp 校验通过）；改动未提交。

## 光标闪烁频率统一（第二轮）
- 用户报告：空项测试块和空块里光标闪烁频率不一致，要求统一且放慢。
- 根因：编辑态有两个光标光源叠加 —— CM6 drawSelection 的 `.cm-cursor`（Obsidian 全局 CSS 剥掉了它的 blink 动画 → 变成一根不闪的常亮 0.67px 细条）+ 我们的 overlay（1.06s 闪烁）。两光源相位漂移 → 观感"不同块频率不一样"。
- 修复：**overlay 成为唯一光源** —— caretOverlay() 扩展里加 `EditorView.theme`：`.cm-cursor { display: none !important }` + `.cm-content` caret-color transparent（theme 随扩展注册，outline/embed 编辑器都覆盖，不用管容器类名差异）；styles.css 里 caret-color 改 transparent、overlay blink 1.06s → **1.2s**（对齐 CM6 cursorBlinkRate，更慢）。
- 验证：probe 显示 `.cm-cursor` display:none、overlay 1.2s；burst 截图 on/off 相位干净（off 相位零残留），空块/行首/中文行首全部一致。
- 已部署主库；未提交。

## 字体粗细与原生编辑器不一致（第三轮）
- 用户报告：插件字体粗细和原生编辑器不一样；提示状态栏按钮可切原生编辑器（同 leaf 原地换视图，`switchToNative`，A/B 对比的现成载体）。
- 根因（复现环境 = 主库 Blue Topaz 主题 + snippets 拷进测试库）：数值字重其实都是 400，真正的差异是两个主题作用域坑——Blue Topaz 把规则限定在 `.markdown-source-view` 上，插件自定义 view 不匹配：
  1. `-webkit-font-smoothing: subpixel-antialiased`（插件漏掉 → `auto` 灰度渲染，笔画发灰发细）；
  2. 字号：原生用 `--font-text-size`（16px），插件从 body 继承 15px——小字号光栅化笔画也更细。
- 修复：`.block-editor-tree` 加 `font-size: var(--font-text-size, 1em)` + `-webkit-font-smoothing: subpixel-antialiased`（与 font-family 的既有修补同款思路）。
- 验证：状态栏 A/B 同 leaf 实测，两边完全一致（400 / 16px / subpixel-antialiased / 霞鹜文楷）；截图笔画粗细一致，圆点对齐未破坏。
- e2e 新坑：插件把 markdown view 类型劫持成 logseq-block-editor，`setViewState({type:'markdown'})` 开不出原生编辑器——必须走状态栏菜单切换。
- 已部署主库；未提交。
