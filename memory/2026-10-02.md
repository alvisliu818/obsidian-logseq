## 混合块(图片+代码围栏)编辑支持(深夜会话,commit 124d104)

用户报告:点击 `![图](...)\n```\ncode` 混合块,整块变成原始文本(图片语法可见)+ 页面跳动。根因是 `parseCodeFence` 只认纯围栏块,混合块走通用编辑器(840px 图片塌缩成一行文字)。

**方案——只换代码元素,不换整块**:
- `parseCodeFence` 接受任意行号的围栏 + `prefix` 字段(围栏前的行);围栏闭合后仍有非空内容 → null(数据安全护栏,防提交丢尾部)。
- 混合块聚焦:重新挂载**缓存的静态渲染**(contentCache WeakMap),只把其中的 `.lgp-code-block` 替换为专用代码编辑器(`replaceEl` 选项)——图片原 DOM 原位保留,布局几乎不变,**滚动位移实测 0**。
- 提交时把静态代码元素放回(`editingWrap.replaceWith(restoreEl)`),文本未变则缓存命中、零闪烁恢复;`parentElement` 判存(isConnected 在 detached holder 上会误判)。
- 混合块工具栏**总是**显示语言标签(lang 为空显示 "text")——它是进入 source mode 编辑前缀的唯一入口;source mode 光标位置要加 prefix 偏移。
- 光标定位:代码编辑器 doc 只含围栏内容,whole-text 坐标(staticPos/数字 pos)要减 `prefix + openLine` 偏移;点击坐标直接 posAtCoords(布局未变,映射准确),偏差 >60px 才回退 staticPos。
- `applyCursorAndScroll` 从 `{y:'center'}` 改 `{y:'nearest'}`(已在屏内则零滚动)——页面跳动的另一半根因。
- **stale editor 守卫**:渲染中途(滚动扩容/索引重建)重挂代码编辑器会泄漏旧 CM6 实例并把死 wrap 留在缓存 holder 里;挂载前 destroy + 还原。

验证:300 vitest(新增 6 个混合块解析测试)+ tsc + esbuild + e2e(混合块:图片保留/编辑器挂载/docLines=15 仅内容/滚动 0/光标在点击处/Esc 完整恢复/落盘结构完整;纯代码块回归:光标按比例映射 line 3/滚动 0/Esc 恢复)。已部署测试库与主库 BaiduSyncdisk。

教训:Playwright `page.evaluate` 只接受 1 个参数(多参数包对象);e2e 断言字符串匹配要考虑缩进(块内围栏带 tab 缩进)。

## 混合块 source mode:语言名点击不再跳动(commit 28b81e7)

用户进一步反馈:点击混合块编辑器工具栏的**语言名**(进入 source mode)页面仍会滚动。根因:source mode 走通用整块编辑器 → 840px 图片塌缩成一行文字 → 页面跳动。

**方案——source mode 也用"前缀静态+原位换码元素"**:
- `mountCodeEditor` 增加 `source` 变体:doc = 围栏源码(openLine+content+fence,标记和语言词可编辑),提交时 `prefix + doc` 原样写回;source 态下再点语言标签只把光标放到第 1 行末尾(不重挂)。
- `mountFocusedInto` 新增混合块 source 分支:`sourceModeBlock === b && parseCodeFence(text).prefix` → 复用缓存静态渲染,只把 `.lgp-code-block` 换成 source 编辑器;纯块保持通用整文本 source 编辑器(其整文本就是围栏源码)。
- **sourceModeBlock 清理改为块级**(`if (sourceModeBlock === b)`):原通用分支无条件清空,导致"聚焦 A 时点击 B 的静态语言标签 → focusBlock(B) 先提交 A 的编辑器 → 把刚设置的 B 的 source 标志清掉"——预存 bug,source mode 从未在"另一块正被编辑"时生效过。
- `renderTree` 静态语言标签:混合块光标偏移要跳过前缀行(找围栏行再累加)。
- stale 编辑器守卫前移到 mountFocusedInto 顶部(覆盖 source 分支)。

e2e(_mix-langlabel.mjs)全过:语言名点击 → 图片保留(imgTop 移 1px)、**anchorDelta=0**、doc line1='```' 17 行、光标 1:3;输入 python+Esc → 静态恢复且标签变 python、落盘 `​```python\n# 搭建模型`;纯块回归(通用 source line1='```python'、Esc 恢复)。301 vitest + tsc + esbuild。已部署主库。
